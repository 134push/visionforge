## 🔧 Git Setup

Clone the repository and connect it with GitHub.

### Initialize Git
`git init` → `git add .` → `git commit`

### Connect to GitHub
`git remote add origin ...` → `git push`

### Update Repository
`git add .` → `git commit -m "Update"` → `git push`
